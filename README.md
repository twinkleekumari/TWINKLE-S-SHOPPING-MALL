# Retail Billing & Invoice Terminal Application

A modular CLI application for point-of-sale customer check-in, dynamic cart manipulation, tax calculation, payment validation, and automated email receipt generation.

## Features
- **Customer Management**: Phone-based CRM check-in and dynamic registration.
- **Cart Consolidation**: Merges repeated items into single line entries automatically.
- **Payment Processing**: Handles Cash with change calculation, Card, and UPI workflows.
- **Digital Invoicing**: Generates formatted plain-text receipts and emails via SMTP.
